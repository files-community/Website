## What's new in Files v4.3.2

### Natural language search

Search in the Omnibar now supports everyday phrases such as "pdfs from last month over 5 mb" or "photos from july". The request is converted into search filters for file type, name, date, and size using the on-device language model included with Windows on Copilot+ PCs. This can be turned off under **Use natural language search** in the Folders settings. (Thanks @yair100!)

### Reordering pinned items in the sidebar

Pinned items in the sidebar can now be reordered by dragging them to a new position. Folders can also be dropped between pinned items to pin them at that position. (Thanks @kalmix!)

### Background server

Settings, file tags, update checks, and the locations shown in the sidebar are now managed by a background process that is shared between all Files windows. This allows windows to stay in sync and lays the groundwork for further performance improvements. (Thanks @hez2010!)
